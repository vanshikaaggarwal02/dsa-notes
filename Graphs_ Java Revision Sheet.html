The pattern: visit each node once, never twice

Almost every graph problem is a traversal with a visited marker. BFS (a queue) explores in rings, so it finds the fewest steps in an unweighted graph. DFS (recursion or a stack) goes deep first, which suits connected components, cycles and “can I reach…” questions.

Grids are graphs. Each cell is a node with up to four neighbours (up, down, left, right). Start a traversal from every unvisited cell to count components. Start one from many sources at once (all rotten oranges, all zeros) to measure distance from the nearest source.

Costs: a traversal is O(V + E) with an adjacency list.
