The pattern: sort, then take the best available choice

A greedy solution makes the locally best choice at each step and never looks back. It works when that choice can be shown not to hurt the final answer (an exchange argument: swapping any other choice for the greedy one cannot make things worse).

Common sort keys: value per weight (knapsack), end time to fit the most intervals, start time to merge intervals, and profit descending for scheduling with deadlines. If a greedy idea fails on a small counter-example, the problem likely needs DP.
