The pattern: monotonic stack

For “next greater / smaller element” problems, keep a stack whose values stay in order (all decreasing, or all increasing). When a new element breaks the order, pop the elements it beats. Each element is pushed and popped once, so the whole scan is O(n).

Spot it: “for each element, find the nearest element to the left or right that is bigger or smaller”, or “count subarrays where this element is the minimum or maximum”.
