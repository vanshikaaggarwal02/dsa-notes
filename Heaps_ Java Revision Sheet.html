The pattern: a heap of size k keeps the k best so far

A heap gives you the smallest (or largest) element in O(1) and lets you add or remove one in O(log n). For “k largest” keep a min-heap of size k: when it grows past k, remove the smallest, so what remains is the k largest. For “k smallest” use a max-heap of size k.

Java’s PriorityQueue is a min-heap. Use new PriorityQueue<>(Collections.reverseOrder()) for a max-heap, or pass a comparator for pairs and arrays.
