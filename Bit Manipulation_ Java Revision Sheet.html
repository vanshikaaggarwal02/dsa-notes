Four identities that solve most of these

x ^ x = 0 and x ^ 0 = x, so XOR cancels pairs. n & (n − 1) removes the lowest set bit. n & −n keeps only the lowest set bit. 1 << i is a mask with just bit i set. Bits are numbered from 0 at the right.
