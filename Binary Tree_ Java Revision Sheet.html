Striver’s A2Z, Binary Trees section (all 32 problems).

The two patterns behind almost every tree problem

1. Recursion that returns information. A function asks the left and right subtrees for a value (height, sum, a flag), combines the two, and returns the result upward. Height, balanced, diameter and max path sum all work this way. When the answer is a “best path through this node”, keep it in a global variable and return only what a parent can use.

2. Level-by-level (BFS). A queue with a loop over the current level’s size handles anything that is about levels, such as level order, views and width.
