Sliding Window / Two Pointers: Java Revision Sheet

Striver’s A2Z, Sliding Window section (all 13 problems). Open a card after trying the problem from memory.

The pattern: a window with a left and a right edge

The right edge moves forward every step and adds a new element. The left edge moves forward only when the window breaks a rule. Each element enters and leaves at most once, so the work is O(n) instead of O(n²).

Spot it: “longest or shortest subarray or substring such that…”, or “count subarrays with…”. For exactly K counting problems, use atMost(K) − atMost(K − 1).
