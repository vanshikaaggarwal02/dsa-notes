How to build any DP solution

  1. State: say in words what dp[i] (or dp[i][j]) means. Most mistakes come from a vague state.
  2. Recurrence: write dp[i] using smaller states. Usually it is “try every choice, keep the best”.
  3. Base cases: the smallest states that you can fill in directly.
  4. Order: fill so that every state you need is already computed (this is tabulation, the bottom-up form). Memoization is the same recurrence written recursively with a cache.
  5. Space: if a row or value depends only on the previous one or two, keep just those and drop the full table.

DP works when the problem has overlapping subproblems (the same smaller question appears again and again) and optimal substructure (the best answer is built from best answers to smaller questions).
